# Граф зависимостей — градостроительные (ГР) проверки

Интерактивная визуализация: **от каких исходных данных зависит каждая ГР-проверка**
и **как ГР-проверки связаны между собой**.

**Открыть:** https://omssng.github.io/gr-graph/

## Что внутри

| Путь | Назначение |
|---|---|
| `index.html` | страница графа (Cytoscape), самодостаточная |
| `data.js` | данные графа: узлы-проверки, узлы-данные, рёбра зависимостей |
| `vendor/` | библиотеки (Cytoscape + раскладки), интернет не нужен |
| `модель/источники-данных.yaml` | каталог узлов «исходные данные» |
| `модель/связи.yaml` | разметка рёбер: связи проверка↔проверка и проверка↔данные |
| `экспорт/граф.graphml` | тот же граф для yEd |
| `экспорт/граф.mmd` | тот же граф в Mermaid |

## Режимы

- **данные → проверки** — источники данных слева, проверки в разделах 1423-ПП справа;
  клик по узлу подсвечивает его связи, двойной клик — изоляция.
- **проверки → проверки** — только зависимости проверок друг от друга; цвет ребра = тип связи
  (результат / предпроверка / переиспользование / вариант / родственная).

Переключатели отрисовки (**блоки / круг**), поиск и фильтры (стадия, раздел, формат, признаки) — на панелях слева и сверху. Клик по узлу открывает панель с критерием и алгоритмом ФЛК.

## Локально

Открыть `index.html` двойным кликом. Если браузер не подгружает `data.js` по `file://`:

```
python -m http.server 8777
```

затем `http://127.0.0.1:8777/`.
